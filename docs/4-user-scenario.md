# 사용자 시나리오 - CJ프레시웨이 프로모션 협업 앱

> 기준 문서: `2-prd.md` (v1.1), `1-domain-definition.md` (v1.8). P0 기능(FR-1~FR-5, FR-7) 중심으로 작성하며, P1(FR-8, FR-9)은 관련 시나리오에 짧게 언급한다. FR-10 이후(페이지네이션/비밀번호변경/재제출/알림/검색/변경이력/대시보드)는 이 시나리오 문서의 범위 밖이며 각 기능 도입 시점의 E2E 리포트(`e2e/` 디렉토리)로 대체한다.

## 시나리오 1. 협력사 담당자의 프로모션 제안 등록

- **액터**: 협력사 담당자
- **사전조건**: 회원가입 전 상태 (또는 이미 가입된 계정 보유)
- **흐름**
  1. 협력사 담당자가 회원가입 화면에서 소속사명, 이메일, 비밀번호, 역할(협력사)을 입력해 가입한다.
  2. 로그인 화면에서 이메일/비밀번호로 로그인한다. 인증 성공 시 access token(메모리)과 refresh token(HttpOnly 쿠키)이 발급되고 협력사용 화면으로 진입한다.
  3. 프로모션 등록 화면에서 기간, 대상 품목(품목명 직접 입력), 조건(할인율/가격 등)을 입력한다.
  4. 필수값을 채우고 제출하면 프로모션이 '제안됨' 상태로 등록된다. (참고: 동일 품목·동일 협력사로 기간이 겹치는 기존 프로모션이 있으면 등록 시 중복 경고가 표시될 수 있다 — FR-9, P1)
- **결과**: 프로모션이 '제안됨' 상태로 생성되어 CJ프레시웨이 담당자에게 노출된다.

## 시나리오 2. CJ프레시웨이 담당자의 프로모션 승인

- **액터**: CJ프레시웨이 담당자
- **사전조건**: '제안됨' 상태의 프로모션이 존재
- **흐름**
  1. CJ프레시웨이 담당자가 로그인 후 검토 대기 중인 프로모션 목록에서 대상 프로모션을 연다.
  2. 기간/대상 품목/조건을 확인한다.
  3. 내용에 문제가 없어 '승인' 처리한다.
- **결과**: 프로모션 상태가 '승인됨'으로 변경된다.

## 시나리오 3. CJ프레시웨이 담당자의 프로모션 반려

- **액터**: CJ프레시웨이 담당자
- **사전조건**: '제안됨' 상태의 프로모션이 존재
- **흐름**
  1. CJ프레시웨이 담당자가 프로모션 상세를 검토한 뒤 조건이 부적절하다고 판단해 '반려'를 선택한다.
  2. 반려사유를 입력한다(필수 항목이며, 미입력 시 처리가 완료되지 않는다).
  3. 반려사유 입력 후 반려를 확정한다.
- **결과**: 프로모션 상태가 '반려됨'으로 변경되고 반려사유가 기록된다. (협력사가 이후 재제안하면 상태는 '반려됨' → '제안됨'으로 전환된다.)

## 시나리오 4. 변경요청 등록 및 반영

- **액터**: 협력사 담당자, CJ프레시웨이 담당자
- **사전조건**: '승인됨' 상태의 프로모션이 존재
- **흐름**
  1. 협력사 담당자가 승인된 프로모션 상세 화면에서 변경요청을 등록한다(변경 내용을 텍스트로 입력).
  2. 변경요청은 '대기' 상태로 기록되며, 조건/기간/대상 품목 등 핵심 조건 변경 요청인 경우 "승인후변경"으로 구분 기록된다(EC-03). 이 경우에도 프로모션 상태는 '검토중'으로 되돌아가지 않고 '승인됨'을 유지한다.
  3. CJ프레시웨이 담당자가 변경요청 내역을 확인하고 실제 프로모션 내용에 반영한 뒤 '반영완료' 처리한다. (내용이 부적절하면 '반영거부' 처리한다.)
- **결과**: 변경요청의 반영여부가 '반영완료'(또는 '반영거부')로 갱신되고, 프로모션 상태/조건 변경 이력이 함께 남는다.

## 시나리오 5. CJ프레시웨이 담당자의 프로모션 취소

- **액터**: CJ프레시웨이 담당자
- **사전조건**: '승인됨' 또는 '진행중' 상태의 프로모션이 존재
- **흐름**
  1. 공급사 또는 내부 사정으로 프로모션을 계속 진행할 수 없게 되어 CJ프레시웨이 담당자가 프로모션 상세에서 '취소'를 선택한다.
  2. 취소사유를 입력한다(필수).
  3. 취소를 확정한다.
- **결과**: 프로모션 상태가 '취소됨'으로 변경되고 취소사유가 기록된다. (참고: 이후 필요 시 CJ프레시웨이 담당자가 취소됨/종료 상태의 프로모션을 '검토중'으로 재오픈할 수 있다 — FR-8, P1.)

## 시나리오 6. 캘린더에서 프로모션 현황 조회

- **액터**: 협력사 담당자, CJ프레시웨이 담당자 (양쪽 모두 동일하게 이용)
- **사전조건**: 로그인 상태, 하나 이상의 진행 중/예정 프로모션 존재
- **흐름**
  1. 사용자가 캘린더 화면에 진입해 월/주/일 중 조회 단위를 선택한다.
  2. 선택한 기간과 겹치는 진행 중·예정 프로모션 목록이 캘린더에 표시된다.
  3. 특정 프로모션을 클릭해 상세 내용(기간/조건/상태 등)을 확인한다.
- **결과**: 사용자가 이메일/전화/엑셀 없이 캘린더 화면만으로 전체 프로모션 현황을 파악할 수 있다.
