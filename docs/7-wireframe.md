# 와이어프레임 - CJ프레시웨이 프로모션 협업 앱

> 기준 문서: `1-domain-definition.md`(v1.4), `2-prd.md`(v1.0), `4-user-scenario.md`, `5-project-principle.md` 6장, `6-arch-diagram.md` 3장
> 전제: 3일/1인 개발 MVP, React 19 반응형 웹(데스크톱 우선). P0 기능(FR-1~FR-5, FR-7) 기준 화면만 포함. 복잡한 대시보드/차트/검색/과도한 필터는 넣지 않는다.

## 0. 반응형 브레이크포인트 전략

- 브레이크포인트는 **1개만** 둔다: `768px` 미만 = 모바일, `1024px` 이상 = 데스크톱(기존 레이아웃 그대로). 그 사이 태블릿 구간은 별도 대응 없이 데스크톱 레이아웃을 그대로 축소해 사용한다.
- CSS 미디어쿼리 1개(`@media (max-width: 767px)`)로 처리하고, 브레이크포인트별 별도 컴포넌트/화면 분기는 만들지 않는다(오버엔지니어링 금지). 표 → 카드, 그리드 → 리스트로 바뀌는 것도 같은 컴포넌트 안에서 CSS로 레이아웃만 전환한다.
- 로그인/회원가입 화면은 원래 세로 폼 구조라 모바일에서도 레이아웃 변경이 없으므로 별도 모바일 와이어프레임을 그리지 않는다(폼 너비만 화면 폭에 맞게 줄어듦).
- 표/그리드가 있는 화면(프로모션 목록, 프로모션 등록, 프로모션 상세, 캘린더)만 아래에 모바일 레이아웃을 추가한다.

## 5. 프로모션 상세 화면 (PromotionDetailPage)

```
+--------------------------------------------------------------+
| 로고   프로모션 상세                                    [목록] |
+--------------------------------------------------------------+
|  상태: [ 승인됨 ]                                              |
|  제안자: ㅇㅇ식품 (협력사)                                       |
|  기간: 2026.09.01 ~ 2026.09.30                                 |
|  대상 품목: 국물떡볶이 500g, 치즈떡볶이 500g                     |
|  조건: 15% 할인, 3+1 사은 지원                                 |
|  (반려 시) 반려사유: -                                          |
|  (취소 시) 취소사유: -                                          |
+--------------------------------------------------------------+
|  액션(*1)                                                     |
|  [협력사]  (등록 후 직접 수정 불가 - 변경요청으로 안내)           |
|  [CJ프레시웨이]  [승인] [수정 후 승인] [반려] [취소]              |
+--------------------------------------------------------------+
|  변경요청                                                      |
|  ------------------------------------------------------------ |
|  [협력사] 변경요청 등록:                                        |
|   [ 변경 내용 입력_________________________ ] [등록]           |
|  ------------------------------------------------------------ |
|  이력                                                          |
|   1) 2026.08.10  요청자: ㅇㅇ식품                               |
|      "가격을 5% 추가 할인해 주세요" (승인후변경)                 |
|      반영여부: 대기   [CJ프레시웨이] [반영완료] [반영거부]        |
|   2) 2026.08.05  요청자: ㅇㅇ식품                               |
|      "사은품 수량을 2개로 조정 요청"                             |
|      반영여부: 반영완료                                         |
+--------------------------------------------------------------+
```

- (*1) 버튼 노출은 역할에 따라 다르다.
  - **협력사 담당자**: 승인/반려/취소/수정 버튼 없음. 등록 후 직접 수정 불가 안내 문구만 표시(EC-01). 변경요청 등록 폼만 사용 가능.
  - **CJ프레시웨이 담당자**: 상태에 따라 승인/수정 후 승인/반려/취소 버튼이 활성화(예: '제안됨'/'검토중'일 때 승인·수정·반려, '승인됨'/'진행중'일 때 취소). 반려/취소 클릭 시 사유 입력 모달이 뜨고 입력해야 확정된다. 변경요청 이력에서 반영완료/반영거부 처리도 CJ프레시웨이만 가능.
- "수정 후 승인"은 상세 화면 상단 필드(기간/대상 품목/조건)를 인라인 편집 가능하게 전환하는 간단한 모드로 처리(별도 화면 분리하지 않음).

**주요 인터랙션**: CJ프레시웨이가 승인/반려/취소 버튼 클릭 시 상태 전이(반려·취소는 사유 입력 필수), 협력사가 변경요청 등록 시 이력에 '대기'로 추가, CJ프레시웨이가 이력 항목에서 반영완료/반영거부 처리.

### 모바일 레이아웃 (< 768px)

```
+---------------------------+

+---------------------------+

```
+--------------------------------------------------------------+

|         [국물떡볶이 프로모션 =========================>]      |

> 구현 참고: 실제 구현(FE-7)은 위 목업의 시각적 스팬 막대 대신, 날짜 셀마다 겹치는 프로모션명을 텍스트로 나열하는 방식으로 단순화했다(데스크톱 포함, 월/주/일 뷰 모두 동일 그리드 컴포넌트 재사용). 완료조건("겹치는 프로모션이 표시된다")을 만족시키는 데 스팬 막대의 폭 계산·겹침 스태킹 레이아웃까지는 필요하지 않다고 판단했기 때문이다.

**주요 인터랙션**: 월/주/일 탭 전환 시 해당 기간과 겹치는 진행 중·예정 프로모션만 재조회해 표시, 막대(프로모션) 클릭 시 프로모션 상세 화면으로 이동.
