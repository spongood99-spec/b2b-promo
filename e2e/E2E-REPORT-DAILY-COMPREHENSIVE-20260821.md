| 1. 목록 필터 → 빈 상태 | 상태 필터를 결과 0건인 값으로 바꾸면 "선택한 상태의 프로모션이 없습니다" 표시 | ✅ |
| 2. 등록 | "상세 조건 (선택)" 섹션을 펼쳐 13개 실무 속성을 전부 입력하고 등록 → 등록 성공 토스트 | ✅ (`"프로모션이 등록되었습니다."`) |
| 3. 목록 행 접근성 | 등록된 행이 실제 `<a href>` 앵커로 렌더링(키보드/새탭 접근 가능) | ✅ |
| 4. 알림 (신규 등록) | CJ프레시웨이 알림함에 "테스트협력사에서 새 프로모션을 등록했습니다." | ✅ |
| 5. "조회" 버튼 | CJ프레시웨이 목록에서 "조회" 버튼으로 수동 재조회 정상 동작 | ✅ |

| 9. 재제출 UI | 반려됨 상태에서 EC-01 안내 대신 "수정 후 재제출" 버튼 노출 | ✅ |

| 11. 알림 (재제출) | CJ프레시웨이 알림함에 "테스트협력사에서 반려된 프로모션을 수정하여 재제출했습니다." | ✅ |

| 13. 알림 (승인) | 협력사 알림함에 "수정된 내용으로 프로모션이 승인되었습니다." | ✅ |

| 타입 | 발생 조건 | 확인 |
|---|---|---|
| `new_promotion` | 신규 등록 | ✅ |
| `rejected` | 반려 | ✅ |

| `approved` | 승인/수정 후 승인 | ✅ |
