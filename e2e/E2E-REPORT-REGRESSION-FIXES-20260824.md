## 의도적으로 조치하지 않은 항목

- **품목 300개 대량 등록 시 응답 지연**: 최대 50개 제한으로 근본 원인(무제한 순차 INSERT) 자체를 제거해 해결.
- **`PATCH /auth/password`에 별도 rate limit 없음**: 이미 유효한 access token이 필요한 인증된 엔드포인트라 우선순위 낮음으로 보류.
- **`partner_cost_share_pct` 소수 허용**: 비즈니스상 문제로 보이지 않아 그대로 둠.
- **폼 작성 중 브라우저 뒤로가기 시 확인창 없음**: 기능 추가 성격이 커 이번 라운드 범위에서 제외.
- **DB에 존재하는 미확인 CJ프레시웨이 계정(`CJFW@naver.com`, `vercel-cj-2026@example.com`)**: 이번 테스트로 생성한 데이터가 아니라 삭제하지 않았다. 실사용자 계정인지 프로젝트팀 확인이 필요하다.
- **변경 전/후 값 이력(감사 로그)**: 타임스탬프는 추가했으나 필드별 diff 기록은 별도 테이블이 필요한 큰 범위라 MVP에서 제외(도메인정의서 5장에 구현 현황으로 명시).
