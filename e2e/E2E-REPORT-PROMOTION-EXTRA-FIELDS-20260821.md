# E2E 테스트 리포트 — 협력사 프로모션 제안 등록 실무 속성 추가 (FR-2 확장)

- **실행 일시**: 2026-08-21
- **대상**: 프론트엔드 `https://cjk-007-fe.vercel.app` + 백엔드 `https://cjk-007-be.vercel.app` (Supabase Postgres 운영 DB)
- **배경**: 식자재 B2B 사업 관점에서 협력사(식자재 제조·공급사) 프로모션 제안 등록 폼에 필요한 실무 속성을 분석해 P0/P1/P2 13개 필드를 전부 추가했다. `docs/1-domain-definition.md` v1.5로 개정하고 5장 Don't 규칙(주문·정산·분석 확장 금지)을 위배하지 않는 범위로 스코프를 조정했다(예상판매량/목표매출은 "분석" 성격이라 제외, 협력사부담율은 합의된 조건 기록만 하고 실제 정산은 하지 않음, 첨부파일은 신규 저장소 인프라 없이 링크 입력으로 대체).
- **실행 방법**: 백엔드는 `node --test` 통합 테스트, 프론트는 `npm run build` + Playwright MCP로 실제 배포본을 조작.

## 1. 추가된 13개 필드

| 우선순위 | 필드 | 설명 |
|---|---|---|
| P0 | 할인유형/할인값 | 기존 "조건" 자유텍스트에 섞여 있던 할인 형태를 구조화 |
| P0 | 협력사부담율 | 프로모션 비용 중 협력사 부담 비율(%). 합의된 조건만 기록, 정산 처리는 하지 않음 |
| P0 | 최소주문수량/공급가능수량 | 발주·재고 계획에 필요한 실무 수치 |
| P1 | 리드타임(일) | 발주~공급 소요일 |
| P1 | 담당자명/담당자연락처 | 로그인 계정과 별개로 프로모션 건별 실무 연락처 |
| P1 | 원산지/인증정보 | HACCP 등 식자재 신뢰성 정보 |
| P1 | 유통기한/보관조건 | 식품 특성상 프로모션 기간과 직결되는 정보 |
| P2 | 프로모션유형 | 신제품출시/시즌행사/재고소진/단순할인/기타 태그 |
| P2 | 적용채널 | 특정 채널/거래선 한정 시 명시(미입력 시 전체) |
| P2 | 첨부링크 | 파일 업로드 저장소 없이 외부 링크로 대체 |

모두 **선택(N) 필드**이며, 등록(`PromotionForm`) · CJ프레시웨이의 "수정 후 승인" · 협력사의 "재제출" 세 곳에서 동일한 `PromotionExtraFields` 컴포넌트를 "상세 조건 (선택)" 접이식 섹션으로 공유한다(필수 흐름을 방해하지 않도록 기본 접힘).
