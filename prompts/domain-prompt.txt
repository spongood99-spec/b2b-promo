너는 최고의 비즈니스 도메인 전문가야. "CJ프레시웨이 프로모션 협업 앱"이란,
협력사(식자재 제조·공급사)가 제안하는 프로모션을 
CJ프레시웨이의 담당자 확인·검토·승인하고, 진행 현황을 협력사와 함께 
소통하며 관리할 수 있는 B2B 프로모션 협업 웹 애플리케이션이라고 해.
다음 내용을 바탕으로 적절한 서브에이전트를 활용해 도메인 정의서 초안을 작성해줘.

## 문제 정의 : 
- 협력사별 프로모션 제안이 이메일·전화·엑셀 등으로 산재되어 있어, CJ프레시웨이 담당자가 전체 현황을 한눈에 파악하기 어렵다.
- 프로모션 제안 → 검토 → 승인/반려 과정에서 협의 내용(가격, 기간, 조건 변경 등)이 대화로만 오가고 기록이 남지 않아 맥락 추적이 어렵다.
- 협력사는 자신이 제안한 프로모션을 직접 수정할 수 없고, CJ프레시웨이만 최종 승인·조정 권한을 가져야 하는데,현재는 권한 구분 없이 임의로 변경되는 경우가 많다.

## 앱의 주요 기능
 1. 회원가입 및 로그인
	- 협력사/CJ프레시웨이 담당자 회원가입 및 로그인
	- 사용자 유형에 따른 역할 및 권한 구분
 2. 프로모션 제안 등록
	- 협력사가 프로모션 기간, 대상 품목, 가격·지원조건 등 제안 정보 등록
	- 등록 완료 후 협력사는 제안 내용을 직접 수정할 수 없음
 3. 프로모션 검토 및 승인
	- CJ프레시웨이 담당자가 협력사의 프로모션 제안 내용 확인 및 검토
	- 필요 시 프로모션 기간, 품목, 가격·지원조건 등 수정
	- 검토 결과에 따라 최종 승인 또는 반려 처리
 4. 프로모션 변경 요청 및 협의
	- 협력사가 등록 이후 변경이 필요한 경우 해당 프로모션의 채팅을 통해 변경 요청
	- CJ프레시웨이 담당자가 변경 요청 내용을 확인하고 협의
	- 최종 변경 여부는 CJ프레시웨이 담당자가 결정하고 프로모션에 반영
	- 프로모션별 협의 내용 및 변경 이력 관리
 5. 프로모션 캘린더 및 현황 조회
	- 월/주/일 단위 프로모션 캘린더 조회
	- 예정·진행·종료 등 프로모션 진행 상태 확인
	- 공급사, 기간, 상태 등 주요 조건을 기준으로 프로모션 조회

## Exception Cases
 EC-01. 협력사가 제출 후 직접 수정 시도
	→ 수정 불가
	→ 변경 요청 기능 안내
 EC-02. 이미 종료된 프로모션 변경 요청
	원칙적으로 변경 불가.
	필요 시 CJFW 담당자가 예외 처리하며 이력을 남긴다.
 EC-03. 승인 이후 조건 변경
	승인된 프로모션의 핵심 조건 변경 시 일반 수정과 구분하여 변경 이력을 남긴다.
	중대한 변경의 경우 향후 재승인(Re-approval) 정책 적용을 고려한다.
 EC-04. 프로모션 취소
	승인 이후 공급사 또는 CJFW 사정으로 취소가 필요한 경우 CJFW 담당자가 최종 취소 처리한다.
	취소 사유를 기록한다.
 EC-05. 일정 중복
	동일 상품 또는 동일 공급사의 프로모션 기간이 기존 Promotion과 중복될 경우 시스템은 경고한다.
	단, 중복 자체를 시스템에서 금지할지 여부는 정책 결정이 필요하다.

## 필수 사항 :
- 도메인 정의서에는 핵심적인 내용만 포함하도록 함 (핵심 액터, 핵심 도메인 엔티티, 유스케이스, 예외케이스 및 비즈니스 규칙)
- MVP 범위(포함/제외)를 명시적으로 구분해서 정리함 
  제외 : 주문·발주·배송·재고, 특히 주문/정산, 재고 실시간 연동, 협력사 등급차등(고객관리), 비용 정산 및 매출/ROI 분석,AI 추천 및 외부 시스템 연계
         포인트 정립, 검색기능, 부과적이고 과한 기능은 이번 개발에서 제외 
- Do :
  ; 프로모션을 중심으로 제안 → 협의 → 승인 → 진행 과정을 관리한다.
  ; 공급사의 제안 권한과 CJ프레시웨이의 최종 결정 권한을 명확히 구분한다.
  ; 주요 협의 및 변경 이력을 추적 가능하게 관리한다.
- Don't
  ; 협력사가 등록 후 프로모션을 직접 수정하거나 승인하게 하지 않는다.
  ; 프로모션과 협의 내용을 분리하여 관리하지 않는다.
  ; MVP 범위를 주문·정산·분석 등으로 과도하게 확장하지 않는다.
- MVP 범위 : 제안 → 협의 → 검토 → 승인/반려 → 변경 → 일정/진행 현황 관리(Promotion Collaboration & Governance)
